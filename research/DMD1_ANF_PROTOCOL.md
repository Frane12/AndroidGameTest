# DRNAS DMD1 — general algebraic discovery, native C++ pilot

## Pre-registered claim

Not a new general SAT solver and not a blind SAT Competition test. A bounded,
source-only mathematical preprocessor can infer non-hardcoded degree-2 ANF
identities, short implied CNF clauses, units and binary equivalences from
locally connected sets of *original* clauses. Benefits must be demonstrated
against a same-core Kissat original and a full-overhead shadow control.

## Method

1. Freeze the first 24 original SHA by SHA sort from the **previously tested**
   EQUIV7 48-source manifest; no outcome-based cherry-picking. Add 4 simple
   synthetic SAT controls solely to validate discovery and proof checks.
2. For each small clause bag (`<=8` variables, `<=12` clauses, seed within first
   1200 source clauses) enumerate its local satisfying assignments. Build the
   evaluation matrix over the monomials `1, x_i, x_i x_j`. Compute GF(2)
   nullspace; each vector corresponds to an identity true on the entire bag.
3. Re-encode short degree-2 identities to candidate CNF clauses; also derive
   units and pairwise equivalences from the same local models. Original clauses
   are never removed. Each inferred clause records the source clause indices.
4. **Independent Python proof replay** exhaustively confirms every appended
   clause follows from just its original source subset, and confirms that the
   augmented DIMACS is precisely original clauses plus checked lemmas.
5. Same pinned Kissat binary, each solver and preprocessor pinned to *one*
   logical CPU; 6-second full E2E cap including preprocessing and independent
   proof replay. Four arms: Kissat original, DMD3 active (soft 3ms algebra
   budget), DMD15 shadow (full prep no lemmas), DMD15 active. Two repeats,
   28 sources, exactly 224 trials. Trial order per SHA is deterministically
   shuffled to mitigate runner scheduling bias.
6. Every SAT witness independently checked against **original CNF**. UNSAT
   is reported as backend-only without independent LRAT; no unverified SAT
   claims, no global solver ranking and no automatic production promotion.
7. Report per arm: total PAR2, total E2E, solved, SAT witness verified,
   unproven UNSAT, number of lemmas, nonlinear identities, abstentions,
   speedup relative to unchanged original Kissat. Include regressions.

## Important limitations

- Local truth-table enumeration is exponential in *bag width* but strictly
  bounded by 8 variables; this is not an efficient general SAT algorithm.
- A small polynomial identity may be true but not useful. Source-only
  lemmas can be redundant with CNF unit propagation/CDCL, so empirical gain
  can be zero or negative.
- The `budget_ms` parameter is a **soft** discovery budget checked between
  bags; input parsing and output writing are charged to actual E2E.
- No proof of an UNSAT solver result is generated by this module. Source-bag
  exhaustive implication proofs are not a complete global LRAT certificate.
- These source CNFs are previously used. Positive results would motivate a
  preregistered fresh SHA holdout, not establish broad superiority.

## Reproducibility

```bash
g++ -std=c++17 -O2 -Wall -Wextra -Werror research/dmd1_anf.cpp -o mre_dmd1/bin/dmd1_anf
python3 research/dmd1_bench.py selftest
python3 research/dmd1_bench.py bench --shard 0
python3 research/dmd1_bench.py audit  # after all four shard JSON files exist
```
