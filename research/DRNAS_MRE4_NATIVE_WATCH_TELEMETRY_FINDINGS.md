## Why this was built

MRE3 demonstrated that importing only two proof-certified binary clauses can
*increase* native CMS propagations, sometimes lower decisions, yet increase
total time. MRE4 tags the exact two binary clauses at native insertion and
counts their real CDCL watch-ID events inside CryptoMiniSat 5.11.15.

Source-pinned to upstream commit 3b709118fd08eb1d15f25e0e239dbc596f967b60.
The source patch is generated by research/mre4_patch_cms.py, fails closed on
unexpected anchors, and instruments exactly:
- Solver::add_clause_int case 2: register ID assigned to the tagged binary
  clause, no fake/heuristic ID mapping;
- PropEngine::prop_bin_cl (non-inprocessing only): per-watch ID visitation,
  enqueued unit-propagation (undefined second literal), detected binary conflict
  (false second literal);
- native bridge only marks selected appended proof-certified CRR clauses.

No raw trial-wide tracing or artificial timestamp logging inside the hot loop.
All trial arms use the same instrumented CMS shared library, pinned original
SHA, frozen native seeds and OTF Gauss OFF. SAT models checked against original
CNF independently and original clauses are never discarded.

## Observed actual CDCL watch-ID telemetry

Four executions per mode: 2 native seeds × 2 timing repeats.

| Arm | Watch visits A+B | Direct unit implications A+B | Direct watched binary conflicts A+B |
|---|---:|---:|---:|
| XOR baseline | 0 | 0 | 0 |
| CRR shadow (no added clauses) | 0 | 0 | 0 |
| Only A | 31,234 | 14,722 | 10 |
| Only B | 38,656 | 16,550 | 0 |
| A+B | 82,868 | 38,798 | 18 |
| All eight certified | 82,244 | 32,000 | 8 |

These count events in the actual non-inprocessing PropEngine::prop_bin_cl hot
path, tagged by the binary clause's native watch ID, not pre-solve probes.
They exclude rewrite/removed watcher IDs, non-binary inprocessing events and
indirect consequences that cannot be attributed to a unique clause.

## Performance under SAME patched CMS library

Proof generation/gate was PRECOMPUTED ONCE for this microbenchmark outside
the per-arm timer. Do not claim these times include full MRE2/MRE3 derivation
cost. Native library is different from the Ubuntu packaged baseline; compare
only arms within this pinned instrumented experiment.

| Arm | 4-run wall sum | mean native propagations | mean decisions | mean conflicts |
|---|---:|---:|---:|---:|
| XOR baseline | 32.629795 s | 1,791,977.5 | 72,344.5 | 56,012 |
| CRR shadow | 32.516283 s | 1,791,977.5 | 72,344.5 | 56,012 |
| Only A | 33.475409 s | 2,222,406.5 | 71,815.5 | 56,008 |
| Only B | 35.035484 s | 1,899,070.5 | 71,203 | 56,005 |
| A+B | 32.773067 s | 2,436,701 | 72,397.5 | 56,013.5 |
| All eight | 32.879528 s | 1,757,155.5 | 72,271.5 | 56,019.5 |

B alone drops native decisions ~1.58% yet is 7.37% slower overall.
A+B has ~35.98% MORE native propagations than XOR-only and is 0.44%
slower on four timing runs. Thus fewer new clauses, more propagations, or
fewer decisions individually DO NOT imply shorter wall time.

Crucially the sign CHANGES by frozen seed:
- seed 1804723611: A+B vs XOR-only: 7.664855 vs 8.134524 s
  and 8.083041 vs 8.446621 s; A+B faster twice;
- seed 3911827663: 8.489132 vs 8.016910 s
  and 8.536039 vs 8.031740 s; A+B slower twice.

The tagged watcher events are real. Yet even an individual event is not proof
of an end-to-end time benefit; the difference includes changed trail,
propagation cascades, clause scanning, decisions, and memory behavior.

## Reliability and limits

- 24/24 runs and independent audit passed.
- Exactly 2 distinct native seeds; repeats give timing variance, NOT
  independent formula evidence.
- One reused/development SAT2026 CNF, NOT blind holdout.
- No independent UNSAT LRAT in this SAT-only pilot.
- Live watch events record both direct units and binary conflicts, but
  do not measure clause-removal/rewrite lineage or CPU cycles per event.
- We should NOT claim a general solver speedup from this pilot.

## Next investigation

Target actual cost per watcher:
- count scans/visits that found already-true or already-false literals;
- count native preprocessor equivalence/variable-replacement events;
- use controlled early-conflict telemetry and reject high-overhead imports;
- preserve MRE3 early-size guard (already gave 1.45x on separate UNSAT case).

Do NOT launch 320 reruns. A small 2-seed, 2-rep test on this same CNF can
diagnose the next hypothesis before a genuinely unseen holdout.
